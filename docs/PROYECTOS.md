# Proyectos del portafolio

Selección de doce proyectos reales del GitHub de Luis Angel Dionicio Bartolo. Las descripciones se contrastaron con los README públicos y el perfil de LinkedIn el 21 de noviembre de 2026. Los enlaces llevan al código original; no se inventan demos, clientes ni resultados de producción. Los seis destacados de la portada muestran variedad entre frontend, backend, aplicaciones móviles e IoT.

| Proyecto | Fuente | Alcance presentado |
| --- | --- | --- |
| FerreMax | [E-commerce-Ferreteria](https://github.com/luisdionicio-lgtm/E-commerce-Ferreteria) | Comercio electrónico e inventario; demo local, Next.js y Express. |
| Factora | [_Factora_Sistema_de-ventas_SUNAT](https://github.com/luisdionicio-lgtm/_Factora_Sistema_de-ventas_SUNAT) | Ventas, existencias y auditoría; boletas en entorno beta sin validez tributaria. |
| Aforo IoT | [FORO-IOT](https://github.com/luisdionicio-lgtm/FORO-IOT) | Arduino UNO, sensores y monitoreo web; prototipo local. |
| CookPlan | [CookPlan](https://github.com/luisdionicio-lgtm/CookPlan) | Aplicación Android de recetas, Room y Firebase; colaboración académica. |
| CeluMarket | [CELUMARKET](https://github.com/luisdionicio-lgtm/CELUMARKET) | CRUD de productos y existencias con Laravel y MySQL. |
| EduControl 360 | [EduControl360](https://github.com/luisdionicio-lgtm/EduControl360) | Portales educativos multiinstitucionales; núcleo inicial, OIDC pendiente de verificación real. |
| G&M Campo | [App_Mobile_GyMelacampos](https://github.com/luisdionicio-lgtm/App_Mobile_GyMelacampos) | Visitas técnicas, medidas manuales, materiales y PDF; backend local compartido. |

| MediGuard AI | [mediguard_web](https://github.com/luisdionicio-lgtm/mediguard_web) | Proyecto académico en equipo; participación de Luis en Android, MVVM, API móvil y UI. No se presenta como servicio clínico validado. |

Las portadas conceptuales están identificadas como ilustraciones. FerreMax utiliza una captura real del repositorio. La publicación previa de otros laboratorios no implica desplegar este portafolio: el despliegue, dominio y página de contacto de la sección TAREA siguen fuera del alcance.
